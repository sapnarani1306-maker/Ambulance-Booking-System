# Ambulance-Booking-System
A C++ based Ambulance Booking System using OOP concepts

## About the Project
The Ambulance Booking System is a console-based C++ application developed using Object-Oriented Programming (OOP) concepts. It helps users book ambulances, check booking status, and cancel bookings.

## Features
- Book an ambulance.
- Check booking status.
- Cancel bookings.
- View available ambulances.
- Admin login.
- Add and remove ambulances.
- View all bookings.
- Calculate ambulance fares.
- Generate revenue reports.
- Save data using file handling.

## Technologies Used
- C++
- Object-Oriented Programming (OOP)
- File Handling
- Vectors and STL
- GitHub

## Ambulance Types
1. Basic Life Support
2. ICU Ambulance
3. Cardiac Ambulance
4. Neonatal Ambulance

## How to Run
Compile the program:

```bash
g++ -std=c++11 main.cpp -o ambulance
```

Run the program:

```bash
./ambulance
```

On Windows, run:

```bash
ambulance.exe
```
